# Python Fundamentals - Profit Calculator

## Project Overview
This is my first Python programming project as part of my journey towards becoming an AI Engineer.

The application calculates the profit generated from a product based on its selling price and product cost.

## Technologies Used
- Python 3

## Features
- Stores product information
- Calculates product profit
- Determines whether a product is profitable
- Displays calculation results

## Example
Product: Massage Cream
Selling Price: RM39.90
Product Cost: RM15.00
Profit: RM24.90
