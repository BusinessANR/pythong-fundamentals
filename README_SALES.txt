# Python E-commerce Sales Analysis

## Project Overview

This is a beginner-level Python practical project designed to analyse e-commerce product sales data.

The project uses Python to calculate product revenue, gross profit, profit margins, and identify top-performing products. It demonstrates how basic programming concepts can be applied to real-world e-commerce business analysis.

## Project Objectives

- Practise Python fundamentals.
- Understand how to work with lists and dictionaries.
- Apply loops, conditional statements, and functions.
- Calculate product revenue and gross profit.
- Identify best-selling and highest-revenue products.
- Analyse product performance by category.

## Dataset

The project uses a sample dataset containing 10 e-commerce products across three categories:

| Field | Description |
|---|---|
| Product | Product name |
| Category | Product category |
| Price | Selling price (RM) |
| Cost | Product cost (RM) |
| Quantity | Units sold |

## Python Concepts Used

- Variables and data types
- Lists and dictionaries
- For loops
- Conditional statements
- Built-in functions (`max()`, `sum()`)
- Lambda functions
- Basic mathematical calculations
- User-defined functions

## Analysis & Calculations

The project explores the following business metrics:

**1. Total Revenue**

`Selling Price × Quantity Sold`

**2. Gross Profit**

`(Selling Price − Product Cost) × Quantity Sold`

**3. Profit Margin**

`(Gross Profit ÷ Revenue) × 100`

**4. Product Performance**

- Best-selling product by quantity.
- Product generating the highest revenue.
- Product generating the highest gross profit.
- Product with the highest profit margin.
- Revenue and profit by product category.

## Key Findings

Based on the sample dataset:

| Metric | Result |
|---|---:|
| Total Revenue | RM33,818.50 |
| Total Gross Profit | RM20,878.50 |
| Best-Selling Product | Nail Polish |
| Highest Revenue Product | Massage Oil |
| Highest Gross Profit Product | Massage Oil |
